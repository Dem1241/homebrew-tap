# homebrew-tap

homebrew formulas for my tools.

```sh
brew install Dem1241/tap/slotwatch
brew install Dem1241/tap/connectwatch
```

- [slotwatch](https://github.com/Dem1241/slotwatch): watch postgres replication slots and catch the one filling your disk with WAL
- [connectwatch](https://github.com/Dem1241/connectwatch): watch kafka connect connectors, see why a task failed and restart it
